# Exercises

These tutorials build complete projects step by step, each using a different part of
AmiForge. They start simple and get harder; do the first two before the others. Each ends with
ideas to try on your own. The finished projects are in the `Examples/Manual` drawer of
AmiForge (and in `examples/manual/` in its source); the exercises call them by the source's
names.

| Exercise | You make | You use |
|---|---|---|
| [1. A first program from a template](01-first-program.md) | `wordcount`, a Shell program | templates, completion, AutoDocs, Build and Run |
| [2. A window made with the GUI designer](02-form-app.md) | a Celsius to Fahrenheit converter | the GUI designer, Generate Code, the USER sections |
| [3. Finding a crash](03-debugging.md) | a fix for a program that crashes | the debugger, the Locals and Call Stack, a conditional breakpoint, a watch |
| [4. Edit and Continue](04-edit-and-continue.md) | a change to a running program | Apply Code Changes |
| [5. Boing BASIC with an extension in C](05-basic-extension.md) | a dice program with a class written in C | a Boing BASIC project, extensions, completion and call tips |
| [6. A round trip to GitHub](06-git.md) | a repository on GitHub | cloning, the Git panel, change markers, commit, push and pull |
| [7. Driving AmiForge from ARexx](07-arexx.md) | a macro and a build script | the ARexx port, the Macros menu, the commands for scripts |

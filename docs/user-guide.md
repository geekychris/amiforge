# AmiForge user guide

The user guide has become the **[AmiForge user manual](manual/README.md)**: one chapter per
subject, with exercises, and appendices listing every key, menu item, ARexx command and file.

- Read it here on GitHub, starting at [the contents](manual/README.md).
- Build the PDF with `make manual-pdf` (it lands in `build/AmiForge-Manual.pdf`).
- On the Amiga, choose **Help > User Manual** in AmiForge: it opens the AmigaGuide version,
  which is installed in `AmiForge/Docs/`.
